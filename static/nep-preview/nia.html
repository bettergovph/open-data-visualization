Station-range length and allocation-per-meter screen

Station ranges are converted to meters (for example, Sta. 0+500–1+015 = 515 m). The ratio divides the row’s House-bill allocation by its parsed station-range total. This is a screening ratio: an allocation can cover multiple work types, and a title can contain several segments or non-linear works. Select the NIA program category before comparing distributions.

Location granularity among resolved codes: 465 barangay, 329 municipality, and 41 city codes. A municipal or city key locates a project only to that administrative area. 1 title contains a latitude/longitude pair, but the workbook has no project point or route geometry layer. These title coordinates and lengths need verification against source plans before spatial or unit-cost analysis. We therefore do not apply FMR road-distance, road-overlap, crop-proximity, endpoint, venue, or connectivity flags to these NIA rows. Those checks need project-level points or line geometry.
