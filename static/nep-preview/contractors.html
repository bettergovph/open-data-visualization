How to read this directory. Contractor names are consolidated by exact normalized name; similar names are not automatically merged. A project association is deduplicated by title, year and contractor, while source records remain separately visible. GAA allocations and source contract values are distinct; cross-source values can overlap and should not be added together. An absent exact GAA link is not proof that a project was unbudgeted.
