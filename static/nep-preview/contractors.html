These are preliminary, document-based observations, not allegations or findings that any person, office, contractor or other entity acted unlawfully. A flag, unmatched record, repeated amount or title, price or location outlier, or missing document is a prompt for review; it does not establish intent, responsibility, benefit, overpayment, duplicate scope or wrongdoing. Source documents, data completeness, parsing, matching, categories, timing and boundaries may affect results. Verify cited primary records and seek relevant context before drawing or publishing conclusions.
How to read this directory. Contractor names are consolidated by exact normalized name; similar names are not automatically merged. A project association is deduplicated by title, year and contractor, while source records remain separately visible. GAA allocations and source contract values are distinct; cross-source values can overlap and should not be added together. An absent exact GAA link is not proof that a project was unbudgeted.

Sources and matching

Project-type filters use exact classified GAA title/year categories where available; otherwise, clear title wording is used. Unclear records are excluded from the type-specific filters. Exact GAA links use normalized title and year and cover classified DPWH road, bridge, flood-control and multi-purpose-building rows in the integrated project dataset. The DPWH FY2016–FY2026 contract list is added as a separate project-record source, with contract links and named parties parsed from the source field. Joint-venture contracts are associated with each named contractor; these associations overlap and must not be summed as unique contracts. DIME, PhilGEPS, DPWH Transparency and the DPWH contract list remain separately reported. Download the 267,292-row DPWH contract Parquet. SEC, PCAB, PhilGEPS registration and AMO fields are exact-name leads from archived reference datasets, not current certifications or proof of ownership, control or benefit.
