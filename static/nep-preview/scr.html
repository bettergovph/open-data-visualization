What the report changes at a glance

Across the four detailed schedules, project rows labeled Removed sum to ₱113,339,418,750 in gross House allocations. DPWH accounts for 3,479 removed rows and ₱99,281,538,750 of that amount. This “Savings” figure is the value of lines removed from the House schedule; it is not a net budget reduction or realized savings, since other lines may be added, restored, renamed or increased.

Separately, DPWH’s General Summary allocation moves from ₱654,102,015,000 in the House bill to ₱587,902,738,000 in the Senate report: net ₱-66,199,277,000. The dataset has 20,835 project rows, 2,719 Annex A rows, 186 Annex B provision amendments, and 37/38 listed checks passing. Source definitions, caveats and documents are recorded in the supplied dataset README.

How SCR changes should affect existing flags

Green · resolved or corrected

Keep the original HGAB flag and add an SCR note when the cited Senate change directly resolves it: for example, the line is cut, a title/location is corrected, or the amount/scope concern is explicitly corrected. The note should cite the SCR page and say what changed.

Red · new or worse

Add a red flag when SCR adds a project that triggers an existing flag rule, or when a Senate revision introduces or strengthens a concern (such as a larger amount, broader scope or a new location/attribution issue). Cite the report page and state the rule triggered.

Review · stage change alone

A cut, rename, addition or increase is not automatically a finding. Match the row to the original flag and its rule first. Preserve historical HGAB evidence, then annotate the later status so the reader can see how the finding changed over time.

This page marks stage disposition from the published dataset. It does not automatically claim that any specific existing flag is invalid or newly substantiated; that requires a defensible row-to-flag match.

Sources and method

The data comes from the supplied senate-2027-dataset package. It covers Senate project schedules for DPWH, DA farm-to-market roads, DOH HFEP and NIA; it is not a complete row-level transcription of every department. Department-wide amounts come from the report’s General Summary. Status and matching conventions are defined in the linked README.

Source validation recorded by the build: 37 of 38 checks pass; the README records page-level misses and describes the remaining review needed. The report pages are evidence references, not proof of implementation or spending.
