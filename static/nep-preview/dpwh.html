How these counts are computed

The denominator is all HGAB project rows. Proposal documents link directly by title or through a selected NEP–HGAB counterpart. Senate PDFs link by exact or accepted relaxed first-page title, or by a file in a uniquely resolved HGAB code. Ambiguous code links are left unassigned. The combined count deduplicates by House row ID; Senate per-type project counts overlap. Signatory names are document-extracted candidates, not verified identities or a current officeholder roster. Photo pages and embedded coordinates are not content-verified. A row without a match is not proof that no document exists.
